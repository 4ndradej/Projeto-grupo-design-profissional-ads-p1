# Postagem Linkedin - Frontend

Desenvolver o Frontend da plataforma da **Tec Maslah** foi uma oportunidade de transformar requisitos e ideias em uma experiência web simples, funcional e intuitiva.
Neste projeto, trabalhamos com uma stack moderna de desenvolvimento Frontend:

• React
• JavaScript
• HTML5
• CSS3
• Vite
• Tailwind CSS
• Git e GitHub

O foco não foi apenas construir telas, mas criar uma experiência que facilitasse a jornada do paciente dentro da plataforma.

Entre as principais funcionalidades desenvolvidas estão:

→ Agendamento de consultas
→ Visualização e acompanhamento de agendamentos
→ Histórico de atendimentos
→ Notificações
→ Interface responsiva e acessível

Um dos pontos mais importantes do projeto foi conectar **UX/UI com desenvolvimento**, garantindo que o resultado final fosse visualmente organizado e, principalmente, fácil de utilizar.

Esse projeto também reforçou uma visão importante sobre desenvolvimento Frontend: escrever código é apenas uma parte do processo. Entender o usuário, os requisitos e o problema que estamos tentando resolver é fundamental para construir uma boa solução.

A Tec Maslah representa, para mim, a aplicação prática de conhecimentos de desenvolvimento web em um projeto completo, passando por análise de requisitos, UX/UI, Frontend, Backend e banco de dados.
